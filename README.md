# GDSC Enetcom — Software Engineering Department Presentations

This repository hosts all session presentations for the **Software Engineering Department** at **GDSC Enetcom**, covering **AI Engineering**.

Each presentation is built as a **React project** rather than a static slide deck, so sessions can include live, interactive demos alongside the theory.

## Structure

Each session lives in its own folder:

```
/01-<topic>
/02-<topic>
...
```

Every folder is a self-contained React app with its own `package.json`.

## Running a presentation locally

```bash
cd XX-<topic>
npm install
npm run dev
```

Then open the local URL shown in the terminal.

## About GDSC Enetcom

GDSC Enetcom's Software Engineering Department curriculum covers AI Engineering, taught through 2-hour sessions structured as 1 hour of theory followed by 1 hour of hands-on project work.
